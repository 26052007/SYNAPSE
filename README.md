# SYNAPSE — The Living Syllabus

A unified, intelligent student station integrating focus tools, scheduling, collaborative learning, and competitive programming tracking into one seamless workflow. Built for the III 5.0 Hackathon organized by Team Gravity at Aparoksha'26.

## 💡 The Problem
Today’s students operate in a highly fragmented digital ecosystem. Staying on top of academics and habits means constantly switching between multiple platforms—a calendar on one tab, a habit tracker on your phone, notes in a separate app, and coding leaderboards entirely disconnected.

This leads to:
- **Context switching overload:** Breaking focus and slowing momentum.
- **Lost productivity:** Too much time spent managing apps instead of studying.
- **Disconnected collaboration:** Sharing notes and discussing projects requires jumping through hoops.

## 🚀 The Solution
SYNAPSE is a unified, distraction-free environment that streamlines the student workflow by integrating essential productivity and learning tools into a single, intelligent interface.

## ✨ Key Features
- **AI Focus Mode:** AI-powered Face/Eye detection to ensure distraction-free study sessions.
- **Smart Calendar:** Centralized scheduling for classes and assignments.
- **Habit Tracker:** Build and maintain academic and personal consistency.
- **To-do List:** Priority-based task management.
- **AI Chatbot:** On-demand assistance.
- **Notes Vault:** Secure, collaborative document storage.
- **Productivity Tracker:** Insights into daily performance.
- **Quiz Games:** Gamified learning.
- **Codeforces Leaderboard:** Track and compete with peers in real-time.
- **Social Features:** Group/Team chats and note-sharing capabilities.

## 🛠 Tech Stack
- **Frontend:** React, Tailwind CSS, HTML, CSS, JavaScript
- **Backend:** Node.js, Flask
